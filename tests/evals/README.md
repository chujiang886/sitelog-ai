# AI 评测集最小可用集占位

本目录将在对应 Agent 实现任务中保存经审核的最小评测集。本任务不创建具体样例，避免杜撰行业输入或期望结果。

## 最低规模

- 每个纳入验收的 Agent：不少于 5 个经审核样例
- 5 个 Agent 合计：不少于 25 个经审核样例
- End-to-End：不少于 5 个经审核样例

## 每个样例必须包含

- 稳定且唯一的样例标识
- 输入与适用前提
- 可靠来源、采集或更新时间、可信度
- 期望结构和允许误差边界
- 禁止出现的幻觉、越权或敏感信息
- 人工审核人和审核状态

具体 Agent 范围与第五个 Agent 的引入时点以架构决策和技术债登记为准；在范围确认前不补造样例。
