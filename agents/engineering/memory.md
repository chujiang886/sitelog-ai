# Engineering Agent 记忆约定（Phase 2.1.5 骨架）

> 骨架阶段：Engineering Agent **无任何持久化记忆**。
> 本文件锁定未来记忆能力的边界，防止实现期随意扩权。

## 当前状态

- 不读写数据库、不落盘、不维护跨请求状态。
- 每次 `invoke` 都是无状态调用：输入 → 分析骨架 → 审核链 → 输出。

## 未来记忆边界（Phase 3+ 评审后启用）

允许记忆（须携带来源与时间戳，进入 Evidence 链）：

- 已验证的工程案例结论（人工审核通过后的案例库条目）。
- 规范库检索结果的引用索引（不缓存规范原文数值本身）。

禁止记忆（防编造 / 防漂移红线）：

- 未经验证的工程数值（任何 `verification_status != verified` 的结论）。
- 用户敏感信息（地址明细、联系方式）。
- LLM 自由生成且无证据链的"经验值"——此类内容一旦入库会被后续
  请求当作事实引用，构成系统性编造。

## 与全局记忆系统的关系

- 项目级事实源：`.ai/project_status.json`（AI 会话 SSOT），
  Engineering Agent 不直接读写该文件。
- 案例库（cases）归 backend 数据层管理；Engineering Agent 未来只能
  通过声明的工具接口访问，不得绕过审核链直写。
