# Design Agent 定义

## 标识

- 名称：Design Agent
- 状态：Phase 0 骨架
- 版本：首次实现时由任务指定

## 职责

在输入与工程依据均已确认后，将环境、视觉和需求信息组织为可审查的设计候选数据，并明确依据和待确认项。

## 输入

- `AgentContext.request_id`
- 用户已确认需求
- Environment 与 Vision Agent 的结构化结果
- 经审核的规则或知识证据

## 输出

`AgentResult`：`data` 保存候选设计描述、适用前提和待审核项，`evidence` 保存每项建议的依据。

## 限制

- 不替代工程师审批、施工图或法定审查。
- 不采用未经确认的行业数值、标准、品牌或型号。
- 输入或依据不足时不生成貌似完整的方案。
- Phase 0 不实现设计业务逻辑或真实模型调用。
