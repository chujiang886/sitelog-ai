## 2. Embedding Provider 设计（复用 ProviderRole.EMBEDDING）

**位置**：`agents/llm/embedding.py`（与现有 LLM provider 同包，复用其约定，不新建并行体系）。

- `EmbeddingProvider(ABC)`：
  - `embed(texts: list[str]) -> list[list[float]]`（批量）
  - `dim: int`（向量维度，ingestion 与 search 必须同实例同维度）
  - 复用 `ProviderRole.EMBEDDING`（`from agents.llm.router import ProviderRole`），作为语义角色标识。
- `MockEmbeddingProvider`：**默认**，确定性哈希向量（输入相同→向量相同，输入不同→余弦可区分），`dim` 默认 64 可配。零外部依赖，CI/Dev 用它。
- `OpenAICompatEmbeddingProvider`：真实 OpenAI 兼容 `/embeddings` 端点（复用 `openai_compat.py` 的 `urllib` 同步 POST + `asyncio.to_thread` 模式，**不引入 httpx/openai SDK**）；`base_url/api_key/model` 来自 env；未配 → `pending_verification` 报错。
- 扩展 `agents/llm/router.py::build_embedding_provider(config)`：
  - `provider: disabled` → `None`（无消费者，保持旧行为，不破坏 `resolve_provider` 既有测试）
  - `provider: mock` → `MockEmbeddingProvider`
  - `provider: openai_compat` + env 解析 → `OpenAICompatEmbeddingProvider`
- **运行时工厂** `backend/app/core/rag/embeddings.py::get_embedding_provider()`：
  - 读 `BOIP_EMBEDDING_PROVIDER` 环境变量（**默认 `mock`**），构造上述类；
  - `openai_compat` 模式下读 `EMBEDDING_*` env（缺省回落 `LLM_A_*` 同源，因 TokenHub 兼服 embeddings）；
  - 未知值 → 抛 `EmbeddingConfigError`（fail-fast）。

**禁止**：默认配置下不建立任何真实 Embedding 网络连接；真实 provider 仅在显式 env 配置后启用（满足"禁止直接接入真实 Embedding 服务"）。

## 3. Qdrant 架构设计（VectorStore 抽象 + 懒加载）

**位置**：`backend/app/core/rag/vector_store.py`。

- `VectorStore(ABC)`：
  - `VectorItem`：id, vector, text, metadata（含 `source`/`created_at`/`raw_ref`/`tenant_id`/`chunk_index`）
  - `SearchHit`：id, score, text, metadata
  - `upsert(items) / search(vector, top_k, tenant_id=None) / delete(ids) / count() / get(id)`
- `InMemoryVectorStore`：**默认**（Dev/CI），余弦相似度检索，进程内存储。
- `QdrantVectorStore`：生产可配置，懒加载 `qdrant_client`（**不进硬依赖**）；读 `QDRANT_HOST/PORT/API_KEY/COLLECTION`；未配置 → 抛 `VectorStoreConfigError`（fail-fast）；`upsert`→points(payload 带 metadata)，`search`→`query_points`。
- `get_vector_store()`：读 `BOIP_VECTOR_STORE` env（**默认 `memory`**）→ InMemory / Qdrant / 未知→fail-fast。

**CI 不依赖外部 Qdrant**：默认 `memory`，`qdrant_client` 仅在 `BOIP_VECTOR_STORE=qdrant` 且配置齐全时才 import；CI 永不到达该分支。

## 4. 文档 chunk 策略

**位置**：`backend/app/core/rag/chunking.py`（或含于 `ingestion.py`）。

- `chunk_text(text, chunk_size=500, overlap=50) -> list[str]`：
  1. 按 `\n` 切分为段落（保留结构语义）；
  2. 贪心地把段落累积进当前 chunk，直至接近 `chunk_size`；
  3. 单段落超 `chunk_size` 时，按字符窗口硬切并带 `overlap` 重叠（避免截断语义）；
  4. 空文本 → `[]`（不入库空 chunk）。
- 参数可配；`overlap < chunk_size` 校验（否则抛 `ChunkConfigError`）。
- 每个 chunk 记录 `chunk_index`，便于溯源与重排。

## 5. source 溯源设计（防编造 / 强制来源）

**硬约束**：每条入库知识必须携带 `source` / `created_at` / `raw_ref`；三者任一缺失 → ingestion 拒绝入库（抛 `IngestionError`），满足"禁止无来源知识入库"。

- `source`：知识来源标识（文件名 / URL / 规则 id / 文档标题）。
- `created_at`：入库时间（UTC ISO）；由 ingestion 自动打，不依赖调用方。
- `raw_ref`：原始引用键（行号 / 外部 doc key / 记录 id），用于回链原文。
- 检索返回结果**必须**携带这三项 metadata，使上层（未来问答链）可追溯、可审计，不把检索片段伪装成已确认事实。

## 6. 检索 API 设计

**位置**：`backend/app/api/rag.py`（新增 router，注册进 `main.py` + `app/api/__init__.py`）。

- `POST /api/rag/ingest`：`{source, raw_ref, text, tenant_id?, chunk_size?, chunk_overlap?}`
  → 调 `ingest_document` → 返回 `{chunk_count, ids, source, raw_ref, created_at}`。
- `POST /api/rag/search`：`{query, top_k=5, tenant_id?}`
  → embed(query) → vector_store.search → 返回 `{items:[{id, score, text, source, created_at, raw_ref, chunk_index}]}`。
- `GET /api/rag/mode`（可观测）：返回当前 `embedding_provider` / `vector_store` 类型（mock/memory 等），便于运维确认未误连真实服务。
- 契约：复用既有错误信封（与 `app/middleware/error_handler` 一致）；`tenant_id` 仅用于隔离检索范围，不强制（基础设施阶段可选）。

## 8. 风险分析

| 风险 | 等级 | 说明 | 缓解 |
|---|---|---|---|
| R1 真实 Embedding 未启用 | 中 | 默认 mock；生产需配置 `BOIP_EMBEDDING_PROVIDER=openai_compat` + env | 上线前运维配置 + 维度对齐验证 |
| R2 向量维度错配 | 中 | mock(64) vs 真实维度不一致 → 检索失败 | ingestion 与 search 强制**同 provider 实例**；真实部署固定 `dim` |
| R3 无来源入库 | 高（红线） | 编造/不可溯源知识进入检索 | ingestion 强制 `source/created_at/raw_ref`，缺则拒（RAG 设计 §5） |
| R4 检索伪装成事实 | 中 | 上层误把片段当确认结论 | 检索仅返回已入库原文+溯源，本 Sprint 不做生成；未来问答链须显式标注 pending |
| R5 覆盖率下降 | 中 | 新增代码未覆盖 | 测试方案 §7 覆盖全部模块；CI 门禁守 85% |
| R6 真实 Qdrant 未端到端 | 低 | 仅 fake client 覆盖逻辑 | 生产首次启用做 smoke（put/get/search） |
| R7 外部依赖渗入 CI | 高（红线） | qdrant-client/openai 误装导致 CI 依赖外网 | 两者均懒加载；CI 默认 mock/memory，永不 import 真实 SDK |

**禁止项落实检查**：
- 禁止直接接入真实 Embedding 服务 → 默认 `mock`，真实仅在显式 env 配置后启用 ✅
- 禁止无来源知识入库 → ingestion 强制 `source/created_at/raw_ref` 校验 ✅
- 禁止重新创建 LLM 体系 → 复用 `ProviderRole.EMBEDDING` + `agents/llm` 抽象，embedding 是单 provider（非双轨）✅
