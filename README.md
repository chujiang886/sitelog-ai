# 施格归档 v5.0 · 公司统一登录

员工入口：https://cj-az.cn/sitelog/ 。管理员分配账号后，员工在任意电脑或手机上用同一账号登录，无需导入分享配置或填写分享 Key。

## 权限和使用

- 管理员：创建、停用员工，重置密码；管理全部工程记录，包括历史记录；配置公司 AI 服务；查看最近操作记录。
- 员工：上传审核记录、生成和下载二维码、管理自己创建的分享。
- 客户：通过二维码链接免登录只读查看；撤回后旧链接失效。
- 初次登录或重置密码后必须修改密码。退出只撤销当前设备会话；改密、重置、停用撤销该账号所有会话。
- AI 是可选功能：管理员在公司设置中配置一次，员工无需填写密钥。没有 AI 配置也可手动整理、导出和分享。

## 开发与验收

`npm ci`、`npm test`、`npm run build`。后端在相邻的 `06_施格归档工程记录` 仓库。

真实浏览器验收（仅使用临时数据）：

```powershell
python ..\06_施格归档工程记录\test_browser_server.py --frontend . --output ./test-output
```

需安装 Chrome，或用环境变量 `TEST_CHROME` 指定测试浏览器。测试覆盖管理员建员工、初始改密、员工上传与人工审核、下载 PNG、二维码解码、手机扫码、多设备登录、停用立即生效。

## 发布

`npm run build` 后只发布 `index.html`、`auth-client.js`、`vendor/` 到服务器版本目录，Nginx 在 `/sitelog/` 提供静态文件。不得发布 `.git`、凭据文件、测试产物或 node_modules。

GitHub Pages 旧入口引导到公司域名；正式页面与 API 同站点，不依赖第三方 Cookie，也没有公开 Token。
